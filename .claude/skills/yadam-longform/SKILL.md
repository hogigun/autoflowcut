# 야담 장편 원고 (70분)

AutoFlowCut 스토리 엔진(W1~W3)의 뼈대를 따르되, 장편·반복 회피용으로 다시 설계한 스킬.
원고 단계만 다룬다. 음성·이미지·캡컷은 PC의 AutoFlowCut에서 이어서 한다.

## 기본값

| 항목 | 값 |
|---|---|
| 분량 | 공백 포함 23,000~27,000자 (목표 25,000자 ≈ 70~75분) |
| 챕터 | 30~36개 (챕터당 600~900자) |
| 시점 | 3인칭 이야기꾼, "~습니다/~지요/~어요" 혼용 |
| 출력 폴더 | `episodes/ep{번호}_{짧은제목}/` |
| 기록장 | `episodes/_log.md` |

글자 수 확인: `python3 -c "import sys;print(len(open(sys.argv[1],encoding='utf-8').read()))" 파일`

## 진행 순서

진행 중에는 단계가 바뀔 때마다 한 줄로 알린다 (`▸ 2단계 설계 시작…`, `✅ 설계 완료`).

### 0단계. 준비 (필수)
1. `episodes/_log.md`를 읽는다. 최근 5편의 조합(오프닝·작법·궁금증 방식·주인공 유형·배경·채널 인사 위치)을 파악.
2. 에피소드 번호 = 기록장 마지막 번호 + 1.
3. 소재가 없으면 → `references/topic-finding.md`대로 소재 후보 3개를 제안하고 사용자가 고르게 한다.

### 1단계. 조사 → `01_조사.md`
- 고증: 시대(왕대), 관직, 신분, 화폐 단위, 풍속, 지명. 틀린 건 고친다.
- 원전·변이형: 청구야담, 어우야담, 계서야담, 동야휘집 등에서 비슷한 설화가 있는지. 있으면 출처를 적어 둔다 (이야기 말미 해설 코너 재료).
- 생활 디테일 10개 이상: 음식, 옷, 도구, 소리, 냄새 (느린 묘사 구간 재료).

### 2단계. 조합 고르기 → `02_설계.md` 상단
`references/rotation.md`의 규칙으로 아래 여섯 가지를 고른다. **최근 3편과 같은 오프닝·작법은 금지, 최근 5편과 여섯 항목이 4개 이상 겹치면 금지.**
1. 오프닝 (`references/openings.md`)
2. 작법 (`references/structures.md`)
3. 궁금증 방식: 시청자도 모름 / 시청자만 앎 / 혼합
4. 주인공 유형 (신분·나이·성별)
5. 주 배경 (장터·관아·산골·포구·양반가·주막·절 등)
6. 채널 인사 위치: 오프닝 직후 / 첫 반전 직후 / 결말 직전

고른 조합과 이유를 사용자에게 한 줄씩 보여 주고 바로 진행한다 (사용자가 바꾸라고 하면 바꾼다).

### 3단계. 설계 → `02_설계.md`
- 선택한 작법의 챕터 틀에 맞춰 30~36챕터 시놉시스. 챕터마다: 한 줄 내용 / 글자 수 목표 / 이 챕터가 만드는 궁금증 또는 기대감.
- 인물표: 주인공, 거울 인물(주인공의 선함·결핍을 비추는 인물), 대비 인물 쌍, 미끼 인물 2명 이상, 숨은 관찰자(있다면).
- 반복 단위: 시험·도전·사건을 3~5회 반복하는 구간을 설계하고, 회차마다 강도를 올리고 결과를 다르게 한다.
- 복선표: 설치 챕터 / 회수 챕터.
- 진실 공개 위치: 전체의 75~85% 지점. 그 전에 시청자가 확신하면 실패.
- **설계 자가 검토** (최대 3회): `references/review.md`의 설계 항목. 통과 후 4단계.

### 4단계. 집필 → `{제목}_1.md` ~ `{제목}_4.md`
- 분량이 길어서 네 부분으로 나눠 쓴다: 1부(오프닝~약 25%), 2부(~50%), 3부(~80%), 4부(끝).
- 한 부를 쓰기 전에 `references/style.md`를 다시 읽는다. 앞 부의 마지막 두 단락을 읽고 이어 쓴다.
- 각 부를 쓴 뒤 글자 수를 재고 설계 대비 ±15%를 벗어나면 그 부 안에서 조정한다.
- 문장·대사는 전부 새로 쓴다. 참고한 영상·원전의 문장을 옮기지 않는다.

### 5단계. 검토 → `03_검토.md`
- `references/review.md`의 몰입도 항목(E) → 문체 항목(S) → 반복 회피 항목(R) 순서.
- 부별로 문제 목록 → 수정. 최대 5회. 0건이면 종료. 5회를 넘으면 사용자에게 남은 문제를 보고.
- 가능하면 검토는 서브에이전트에게 맡긴다 (작성자와 검토자 분리). 부별로 병렬 가능.

### 6단계. 사용자 확인 🛑
- 보여 줄 것: 제목 후보 3개, 조합 요약, 총 글자 수·예상 길이, 검토 점수, 파일 목록.
- 승인되면 `episodes/_log.md`에 한 줄 추가하고 커밋·푸시.
- 이후 PC의 AutoFlowCut에서 음성·이미지 단계로 넘어가는 방법은 저장소 `CLAUDE.md` 참고.

## 참조 파일
- `references/openings.md` — 오프닝 6종
- `references/structures.md` — 작법 6종과 36챕터 배분
- `references/rotation.md` — 조합 규칙과 채널 고유성 장치
- `references/style.md` — 문체·금지어·장편 호흡
- `references/review.md` — 검토 체크리스트
- `references/topic-finding.md` — 소재 찾기
