# 문체 규칙 (TTS 낭독 전제)

## 기본
- 3인칭 이야기꾼. 종결은 "~습니다 / ~지요 / ~어요"를 섞되 한 단락 안에서 같은 어미가 세 번 연속되지 않게.
- 대사는 사극 말투, 신분에 맞게 (윗사람→아랫사람 하대, 아랫사람→윗사람 높임).
- 문장은 짧게. 한 문장 50자 안팎, 긴장 구간은 20자 안팎.
- 호칭은 이름·관계·직함으로 (낭자, 도령, 마님, 대감, 할멈, 아씨).

## 금지 (TTS와 시대감)
| 금지 | 대신 |
|---|---|
| 감정 직접 명명 ("슬펐습니다") | 몸·행동·소리 ("입술을 깨물었습니다") |
| 말줄임표 | 마침표나 쉼표 |
| 영어·외래어 | 우리말 |
| 아라비아 숫자 | 한글 수사 ("여덟 시"가 아니라 "술시", "서른 냥") |
| 현대 어휘 (스트레스, 체크) | 시대 어휘 |
| "하녀" | 몸종, 침모, 찬모, 계집종 |
| "~씨" 호칭 | 성+직함, 택호 |
| "그녀" 남발 | 이름·호칭 (필요할 때만 "그이") |

## 장편 호흡 (70분)
- 느린 구간과 빠른 구간을 번갈아: 생활 묘사(오감) 2~3챕터 → 사건 1~2챕터.
- 느린 묘사도 반드시 복선 하나를 품는다 (그냥 풍경은 금지).
- 정보는 덜 준다. 이야기꾼이 의미를 해설하지 않는다. 사실만 주고 해석은 시청자가.
- 위기·해결 장면은 짧은 문장, 동사, 소리 중심.
- 10분마다(약 3,500자) 작은 질문 또는 반전 하나.
- 교훈·격언은 설치 한 번, 회수 한 번만.

## 끝맺음
- 여운 → (선택) 해설 코너 → 구독 요청. 구독 요청 문장은 편마다 다르게 쓴다.

## 시니어 모드 (사용자가 켜면 적용)
- 주요 인물 4~6명, 이름은 소리가 확실히 다르게. 부를 때 "바느질방 달래"처럼 설명을 붙인다.
- 약 10분(3,500자)마다 이야기꾼이 지금까지 상황을 한두 문장으로 되짚는다 (문장은 매번 다르게).
- 본편은 시간 순서대로. 회상은 짧게 한두 번만, 교차 서술은 쓰지 않는다.
- 잔혹·공포 묘사는 짧게. 악인은 벌을 받되 벌 장면을 끌지 않는다.
- 닫힌 결말: 선한 인물의 보상, 가족·관계의 회복.

## TTS 띄어쓰기 (편집본과 TTS본 분리)
- 편집용 원고는 맞춤법대로 쓴다. TTS가 끊어 읽는 띄어쓰기는 `python3 tools/tts_prep.py <에피소드 폴더>`로 `원고_TTS용.txt`에서만 붙인다.
- 붙이는 규칙: 성+호칭(심대감), 수사+단위(아흔아홉칸, 한땀), 굳어진 소품 이름(푸른실), 본용언+보조용언(끊어낸).
- 새 편마다 인물 호칭과 소품 이름을 스크립트의 NAME_TITLES, FIXED_PHRASES에 더하고, `04_TTS변환목록.md`에서 잘못 붙은 곳이 없는지 확인한다.

## 인트로
- 첫 30초는 두 인물이 주고받는 대사 4~6줄로 연다. 절정 직전 장면에서 가져오되 답은 주지 않는다.
- 대사 뒤 내레이션으로 질문 세 개(왜, 무엇, 결과)를 던지고 "이야기는 그날 ○○로 거슬러 올라갑니다"로 본편에 잇는다.
