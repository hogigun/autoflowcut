# 조합 규칙과 채널 고유성 장치

유튜브는 채널 전체에서 같은 틀이 반복되는지, 사람이 더한 가치가 있는지를 본다.
이 규칙은 위험을 낮추는 장치일 뿐 보장이 아니다. 사람의 손길(아래 H 항목)이 함께 있어야 한다.

## 조합 규칙
1. 오프닝·작법: 최근 3편과 겹치면 안 된다.
2. 여섯 항목(오프닝, 작법, 궁금증 방식, 주인공 유형, 배경, 인사 위치) 중 최근 5편 어느 한 편과 4개 이상 같으면 안 된다.
3. 궁금증 방식은 같은 것이 3편 연속되면 안 된다.
4. 주인공 유형 예시 풀: 아이, 노인, 과부, 머슴·노비, 기생, 몰락 양반, 상인, 장인, 승려, 무관, 의원, 사냥꾼, 뱃사람, 무당.
5. 시대도 돌린다: 조선 전기 / 중기 / 후기 / 고려 / 시대 불명(설화).
6. 제목 틀도 돌린다: [인물+행동, 반응+이유] / [대사 인용] / [숫자 없는 질문형] / [결과 선공개형].

## 채널 고유성 장치 (H, 편마다 2개 이상 권장)
- H1 해설 코너: 결말 뒤 1~2분. 원전 출처, 실제 역사와 각색의 경계, 당시 풍속 한 가지.
- H2 이야기꾼의 한마디: 채널만의 말버릇·맺음말. 매번 같은 문장 말고 같은 "태도"로.
- H3 사용자 손질: 초안 뒤 사용자가 직접 고친 부분(대사·장면)을 `03_검토.md`에 기록.
- H4 시청자 참여: 딜레마 질문으로 댓글 유도 (매번 다른 질문).
- H5 고유 목소리: TTS라면 채널 전용 목소리·속도 고정, 가능하면 직접 녹음.
