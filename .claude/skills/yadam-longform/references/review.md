# 검토 체크리스트

## 설계 검토 (3단계)
- [ ] 모든 챕터가 궁금증 유지 또는 기대감 쌓기 중 하나 이상에 기여하는가
- [ ] 미끼 인물 2명 이상, 반전 2겹 이상
- [ ] 시청자가 진실을 확신하는 최초 지점이 75% 이후인가
- [ ] 반복 단위가 회차마다 강도·결과·새 정보가 다른가
- [ ] 복선표의 모든 복선이 회수되는가
- [ ] 챕터 글자 수 합계가 23,000~27,000자인가

## 몰입도 (E, 최우선)
- E1 세 단락 연속 질문 없는 구간이 없는가 (있으면 이탈 구간 → 다시 쓰기, 삭제 아님)
- E2 오프닝 장면이 본편에서 다른 의미로 다시 나오는가
- E3 10분(약 3,500자)마다 작은 질문·반전이 있는가
- E4 진실 공개가 궁금증을 닫으면서 여운(새 감정)을 여는가

## 문체 (S)
- S1 `style.md` 금지 항목 위반 0건 (숫자·영어·말줄임표는 기계적으로 검색)
- S2 감정 직접 명명 0건
- S3 같은 어미 세 번 연속 없음
- S4 이야기꾼의 해설·교훈 반복 없음

## 반복 회피 (R)
- R1 `_log.md` 최근 5편과 조합 규칙 위반 없음
- R2 최근 편들과 같은 대사·비유·장면 묘사를 재사용하지 않았는가 (최근 2편 원고 검색)
- R3 참고한 영상·원전의 문장을 옮기지 않았는가
- R4 채널 고유성 장치(H) 2개 이상

## 점수
E 40점, S 30점, R 30점. 95점 미만이면 수정. E 항목 하나라도 실패하면 점수와 관계없이 수정.
