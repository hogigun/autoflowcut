# 소재 찾기

## 0. 카테고리 제약 (2026-10-04)
- 채널은 **고부(姑婦) 이야기**로 맞춘다. 후보는 모두 시어머니–며느리 관계가 중심축이어야 한다.
- 쓴 것(기억 파일 2026-10-04): 7편 박씨며느리(허물), 8편 시루 = 신통력·이상한 명령 고부. 쓴 물건: 메주·개·누더기·이불·요강·싸라기·보따리·허물·시루 → 제목 중심 물건으로 다시 쓰지 않음.
- 신통력은 7·8편에서 연속으로 썼으므로 9편은 신통력 없는 장치(문헌 편지)로 간다. 신통력을 다시 쓸 때는 편당 한 가지, 한도를 둔다(꿈은 뜻을 모름 등). 중심은 늘 "시어머니와 며느리가 서로를 믿게 되는 과정".
- 남은 후보(기억 파일): 옷고름 속 언문 편지(9편 1순위) / 꼬마며느리(예비) / 자매문기(10편, 7편 예고 약속) / 교전비(보류) / 분재기(겹침 큼). 상세는 `episodes/ep09_기획/00_소재후보_시장조사.md` 3차 조정.
- 고르는 순서: ① 제목 한가운데 놓을 이상한 물건이 있는가 → ② 고부 축이 중심인가 → ③ 문헌 장치가 있는가(해설 코너) → ④ 시장 신호 → ⑤ 겹침 표시(탈락 아님).
- 흐름 뼈대(keep-proven-flow): 이상한 물건 → 여정에서 하나씩 쓰임 → 결말에서 회수 → 어른의 지혜·대물림.

## 0-1. 겹침은 표시만
겹침 검사는 탈락 기준이 아니다. 시장 공식과 같아도 내용·포장(주인공·배경·신통 종류·오프닝·제목 틀·오감)이 바뀌면 쓴다. 후보마다 "같은 것 / 바꾸는 것"을 한 줄씩 적는다.

## 1. 폭발 영상에서 패턴 뽑기
- vidIQ `vidiq_outliers` (language=ko, contentType=long, 키워드: 야담·옛날이야기·민담·사연, 최근 한 달). 1회 5크레딧 — 호출 전 잔액 확인.
- 크레딧이 없거나(월 150, 매월 7일 충전) youtube.com·vling·vidiq.com 등이 네트워크 정책에 막히면: 웹 검색(`site:youtube.com 야담 ○○`)으로 제목 공식·테마별 공급 밀도·업로드 최근성을 본다. 수치는 못 얻으니 "검증된 틀인가"만 판단한다.
- 기준: 구독자 대비 조회수 5배 이상, 최근 2~4주.
- vidIQ를 못 쓰면 사용자에게 제목·조회수·구독자 수나 스크립트 일부를 붙여 달라고 한다.
- 뽑을 것: 주인공 유형, 첫 행동, 반전 종류, 감정(감동·통쾌·공포), 제목 틀. 줄거리·문장은 가져오지 않는다.

## 2. 확인된 패턴 (2026-09 분석)
- 약자의 작은 선행 반복 → 숨은 관찰자 → 정체 공개와 보상
- 장터·서민 생활 배경, 감동·보상형 결말 ("잠잘 때 듣는" 수요)
- 시험·도전 반복 구간으로 분량 확보

## 3. 후보 만들기
패턴 하나 + 원전 설화 하나 + 새 조합(주인공·배경·시대)을 섞어 후보 3개를 만든다.
각 후보: 한 줄 줄거리 / 주인공 / 반전 / 추천 작법 / 제목 예시 / 최근 편과 겹치는 점.
