# 오프닝 6종

오프닝은 1분 안팎(700~1,200자). 목표는 하나: **시청자가 "왜?" 또는 "그래서 어떻게 돼?"를 품고 본편으로 넘어가게 하는 것.**
아래 예시는 형식 설명용이다. 예시 문장을 그대로 쓰지 말고 매번 새로 쓴다.

| id | 이름 | 형식 | 잘 맞는 궁금증 방식 |
|---|---|---|---|
| O1 | 중간 장면 | 이야기 중반의 긴장된 순간을 대사 한 줄로 시작 → 말이 안 되는 선택 → 주변 반응 → 질문 1~2개 → 본편은 처음부터 | 시청자도 모름 |
| O2 | 결말 먼저 | 결과(보상·몰락·재회)를 먼저 말하고, 그 결과가 믿기지 않는 이유를 던짐 | 시청자도 모름 |
| O3 | 비밀 공유 | 시청자에게만 인물의 정체·계략을 알려 주고, 당사자는 모른다는 사실을 강조 | 시청자만 앎 |
| O4 | 마지막 말 | 누군가 남긴 한마디(유언·편지·부탁)의 뜻을 아무도 모른다는 데서 시작 | 시청자도 모름 |
| O5 | 조용한 풍경 | 소리·냄새·빛으로 한 장소를 천천히 그리다가 마지막 문장에서 이상한 점 하나를 드러냄 (수면용 채널에 적합) | 혼합 |
| O6 | 이야기꾼의 물음 | 이야기꾼이 시청자에게 직접 묻는다 ("여러분이라면 어찌하시겠습니까?") → 딜레마 제시 | 혼합 |

## 공통 규칙
- 첫 세 문장 안에 인물 + 이상한 점이 나온다. "어느 날"로 시작하지 않는다.
- 오프닝에서 쓴 장면은 본편에서 반드시 다시 나오고, 그때는 의미가 달라져 있어야 한다.
- 질문은 최대 두 개. 답을 암시하지 않는다.
- 채널 인사는 `rotation.md`에서 고른 위치에 넣는다. 오프닝 직후가 아니면 오프닝은 곧바로 본편으로 이어진다.
- "옛날 옛적"은 본편 첫 문장에 쓸 수 있으나 필수 아님. 최근 2편이 썼으면 다른 도입(시대·계절·장소로 시작)을 쓴다.

## 형식 예시 (원문 새로 작성)
- O2: "그해 겨울, 고을에서 가장 가난하던 짚신 장수의 집 앞에 사또가 직접 가마를 세웠습니다. 불과 석 달 전, 그 짚신 장수는 관아 앞에서 매를 맞고 쫓겨난 사람이었지요."
- O3: "주막 부엌에서 설거지를 하는 늙은 머슴이 사실은 이 고을의 암행어사라는 것을, 주막 사람들은 아무도 몰랐습니다. 그리고 오늘 밤, 주모의 딸이 그 머슴의 밥그릇에 무엇을 담는지가 이 고을의 운명을 가르게 됩니다."
