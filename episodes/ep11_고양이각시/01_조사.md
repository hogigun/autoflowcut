# 01. 조사 — 고양이 각시 (11편 가칭)

> 기준: `yadam-longform` 스킬 1단계 (`claude/lucid-cannon-7ddyj4` 브랜치의 스킬 + `claude/busy-bardeen-sgdrqd`의 채널 합의 사항)
> 기획 근거: `plans/03_goyangi-seoreun-mari.md` (3차 수정안)
> **확인 필요** 표시가 붙은 항목은 해설 코너에 쓰기 전에 원문을 한 번 더 확인할 것.

## 1. 시대·장소
| 항목 | 정함 | 근거·메모 |
|---|---|---|
| 시대 | 조선 후기, **숙종 말엽** (원고에서는 왕대를 말하지 않고 "숙종 임금 시절"로 한 번만) | 상평통보(엽전)가 숙종 4년(1678)부터 널리 쓰여 장터 엽전 거래가 자연스러움. 해설 코너의 숙종 고양이 일화와 이어짐 |
| 장소 | 전라도 **담양** 고을 산골 마을 "대숲골" (가상의 마을) | 담양은 예부터 대나무 고장. 대숲·죽물(대나무 세간) 장터 묘사에 맞음 |
| 친정 | 고개 너머 들판 마을 "들말" (가상) | 보름이 친정아버지가 장터 **말감고**(되질하는 사람)라 되를 읽을 줄 아는 근거 |
| 계절 흐름 | 늦봄(혼인, 대꽃) → 여름(장마, 대나무 열매) → 늦여름(쥐 굴) → 가을걷이 열흘 전(쥐 떼) → 가을(향회) → 이듬해 봄(새끼 고양이) | 한 해 안에 닫히는 이야기 |

## 2. 고증 항목
| 항목 | 내용 | 원고 반영 |
|---|---|---|
| **장리(長利)** | 봄에 곡식을 빌려 가을에 절반을 이자로 얹어 갚는 사채. 한 섬 빌리면 한 섬 반 | 곽 부자의 돈놀이. "장리쌀" |
| **되·말** | 관에서 정한 되가 있었지만 고을·집마다 크기가 달라 다툼이 잦았음. 사사로이 큰 되로 받고 작은 되로 내주는 폐단은 조선 후기 여러 기록에 불만으로 나옴 (일반 서술, 특정 기록 인용은 하지 않음) | 곽 부자의 큰 되·작은 되. 되 바닥의 집안 낙인 |
| **말감고** | 장터에서 곡식을 되어 주던 사람 | 보름이 친정아버지. 보름이는 어려서 되 눈금을 보며 자람 |
| **향회·향약 벌칙** | 마을 일을 의논하는 모임. 향약에는 잘못한 사람을 마을이 상종하지 않는 벌(손도), 마을에서 내보내는 벌(출향) 등이 있었음 | 곽 부자가 받는 벌은 "손도"와 관아 고발. 벌 장면은 짧게 (시니어 모드) |
| **좌장** | 향회를 이끄는 어른 | "윤 좌장 어른" |
| **비상(砒霜)** | 비소 독. 실제로 쥐약으로 쓰였음 | 곽 부자가 생선에 섞음. 쥐약을 고양이에게 쓴다는 아이러니 |
| **녹두** | 민간에서 여러 독을 푸는 데 녹두를 달여 먹였다는 처방이 전함 (동의보감의 녹두 해독 항목, **확인 필요**) | 보름이가 녹두 삶은 물로 고양이를 살림 |
| **대나무 꽃과 쥐** | 대나무는 수십 년에 한 번 한꺼번에 꽃 피고 열매(죽실)를 맺은 뒤 마름. 열매를 먹은 들쥐가 크게 불어나는 일은 여러 나라에서 기록된 생태 현상 | 핵심 장치. 원고에서는 할머니의 경험담으로만 전달 |
| **죽실(竹實)** | 흉년에 대나무 열매를 따 먹었다는 이야기가 전함 (조선 기록의 구체 연대는 **확인 필요**) | 마을 아이들이 "대나무 쌀"이라며 주워 먹는 장면 |
| **산판** | 나무를 베어 내는 산. 비탈 작업은 위험 | 시아버지가 장맛비 속 산판에서 통나무에 깔려 죽음 |
| **택호** | 여자를 친정 마을 이름으로 부름 ("윗말댁") | 시어머니 = 윗말댁. "~씨" 호칭 금지 규칙에 맞춤 |
| **무명 값** | 18세기 초 무명 한 필은 대략 엽전 두 냥 안팎으로 거래됐다고 봄 (지역·해마다 차이 큼, 원고엔 숫자를 쓰지 않음) | "무명 세 필과 은가락지 한 쌍 값" |
| **쥐막이** | 곳간·볏가리 기둥에 판을 달아 쥐가 못 오르게 하는 장치. 일본의 네즈미가에시 같은 형태가 알려져 있고, 우리 쪽 기록은 분명하지 않음 → **각색** (보름이 할머니가 고안한 것으로 처리) | 대나무를 쪼개 엮은 둥근 판. 해설 코너에서 각색임을 밝힘 |

## 3. 원전·변이형 (해설 코너 재료)
| 자료 | 내용 | 쓰임 |
|---|---|---|
| **숙종의 고양이 "금손"** | 숙종이 아끼던 고양이가 임금이 승하하자 먹이를 끊고 따라 죽었다는 이야기. 이익 『성호사설』의 「금묘(金猫)」, 김시민의 「금묘가」에 전함 (**확인 필요**: 편명·문장) | H1 해설: "숙종 임금 시절, 궁궐에도 고양이를 아낀 분이 계셨지요" |
| 고양이 영물 속신 | 고양이는 영물이라 해치면 앙갚음한다, 집에 들이면 재수 없다는 상반된 속신이 함께 전함 | 시어머니의 첫 반대 이유. 곽 부자의 고양이 혐오 |
| 개와 고양이의 구슬 | 은혜 갚은 개와 고양이 민담 (구슬을 되찾아 주는 이야기) | 직접 쓰지 않음. 고양이 보은 정서만 참고 |
| 장리·되 다툼 | 조선 후기 향촌 고리대 문제 일반 | H1 해설: "곳간의 되가 두 개였던 까닭" |

> 원작 문장은 가져오지 않는다. 구조와 정서만 참고한다.

## 4. 생활 디테일 (느린 묘사 구간 재료, 14개)
1. 대숲 바람 소리: 댓잎끼리 비비는 "사르륵" 소리, 바람이 세면 대가 서로 부딪쳐 "딱, 딱"
2. 죽순 캐는 늦봄 새벽, 이슬 젖은 짚신
3. 대나무를 쪼개 바구니 엮는 소리, 칼날에 댓살 갈라지는 소리
4. 하얀 대꽃: 벼꽃처럼 가늘고 늘어진 꽃이삭, 누런 꽃가루
5. 대나무 열매: 보리알 같은 갈색 낟알, 아이들이 "대나무 쌀"이라 부르며 주움
6. 생선 대가리 비린내, 소금 뿌린 갈치 꼬리, 장터 끝 갯가 할멈의 지게
7. 헛간 짚 냄새, 고양이 서른 마리의 그르렁 소리, 새벽에 발등에 올라오는 따뜻한 털
8. 녹두 삶는 냄새, 사기 대접에 식혀 숟가락으로 떠 넣기
9. 다듬이 방망이 소리 (시어머니가 화날수록 빨라짐)
10. 장리쌀 되질: 되에 쌀을 붓고 방망이(평미레)로 깎는 소리 "스윽"
11. 늦여름 밤 들판의 "사각사각" 소리, 볏잎 끝이 잘려 나간 자국
12. 장맛비가 초가 처마에서 떨어지는 소리, 산판의 통나무 미끄러지는 소리 (회상)
13. 쥐 떼의 밤: 담장 위로 물결치는 검은 등, 짚 지붕 속 발소리, 곳간 벽 흙이 부스러지는 소리
14. 이듬해 봄 툇마루 볕, 새끼 고양이의 젖 냄새, 시어머니 무릎의 무게

## 5. 피해야 할 것
- 주인공은 **열아홉 성인**. "꼬마·아이·어린이"라는 말로 주인공을 부르지 않음 (YPP, 이미지 생성)
- **고양이는 한 마리도 죽지 않음**. 비상 장면은 앓다가 살아나는 데까지만
- 쥐 떼는 소리와 물결 같은 실루엣으로. 물리는 장면·사체 묘사 없음
- 시아버지 죽음은 사고 경위만 짧게. 곽 부자가 직접 해치지는 않았음 (위험한 비탈로 보낸 책임)
