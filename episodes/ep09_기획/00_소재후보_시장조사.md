## 2. 후보 5개 (추천 순)

### 1순위. 사윗감 셋을 시험한 포구 국밥집 과부
- **타는 공식**: G(거지 행색 시험) + A(발칵 뒤집힌 이유) + 떡집·국밥집 배경. 9월 폭발작 '떡집 할머니(며느리감 시험)'의 **성별 뒤집기 + 포구 포장**.
- **한 줄**: 남해 포구에서 국밥집을 하는 과부 주모가 외동딸의 혼처 셋(객주 아들, 글 읽는 선비, 말 더듬는 뱃사람 머슴)을 거지 노파로 꾸며 세 차례 시험한다. 그런데 주모가 시험하는 동안, 누군가 주모를 시험하고 있었다.
- **주인공**: 마흔 중반 과부 주모(중년 여성). 거울 인물: 열일곱 외동딸. 미끼: 객주 아들(겉 좋은 사람), 선비(겉 반듯). 숨은 관찰자: 주모가 아니라 **머슴을 거둔 늙은 뱃사람**(실은 전 수군 만호, 딸의 외할아버지의 옛 동무).
- **반전 2겹**: (1) 머슴이 통과 → (2) 주모 자신이 '딸을 팔지 않는 어미인지' 시험받고 있었고, 포구 객주의 빚 문서가 그 시험의 도구였다.
- **반복 단위**: 시험 3회(국밥 한 그릇 / 비 오는 밤 노 젓기 / 빚쟁이 들이닥친 날) × 사윗감 3명 = 9장면, 회차마다 강도↑·결과 다름.
- **조합 제안**: 오프닝 O1(중간 장면: "그 국밥, 노파에게 주어라") / 작법 S1(시험 반복) / 궁금증 혼합(주모의 변장은 시청자만 앎, 누가 주모를 보는지는 모름) / 배경 포구·객주 / 시대 조선 후기(정조 무렵) / 인사 첫 반전 직후 / 제목 틀 결과 선공개형.
- **제목 후보**: ① 사윗감 셋을 거지 노파 행색으로 시험한 포구 국밥집 과부, 마지막 밤 무릎을 꿇은 사람은 따로 있었다 ② 국밥 한 그릇으로 사위를 고른 과부, 삼 년 뒤 포구가 발칵 뒤집힌 이유 ③ "그 국밥, 저 노파에게 주어라" 말 더듬는 뱃사람 머슴의 한마디
- **문헌 걸이(H1)**: 청구야담·어우야담의 '사위 고르기' 유형, 조선 후기 포구 상업(객주·여각·어염), 수군 만호 제도.
- **1편과 같은 것 / 바꾸는 것**: 같음 = S1 시험 엔진, 숨은 관찰자, 혼합 궁금증. 바꿈 = 주인공(젊은 침모→중년 과부 주모), 배경(북촌 양반가→남해 포구), 오감(인두·다듬이→갯내·젓갈·노 젓는 소리), 오프닝(O3→O1), 인사 위치, 제목 틀, 미스터리 장치(장부 암호→없음, 사람 시험으로 단순화).
- **위험**: '시험' 엔진이 1편·폭발작과 동일 → 포장(포구·성별 뒤집기·이중 관찰자)이 흐려지면 반복 콘텐츠로 보일 수 있음. 설계에서 이중 관찰자를 반드시 살릴 것.

### 2순위. 흉년에 곳간을 연 구두쇠 영감
- **타는 공식**: A(발칵 뒤집힌 이유) + 정체 공개(구두쇠가 사실은 은인) + G(시험)의 변형(시험이 **공개적**이라 모두가 영감을 욕함). 흉년·구휼 테마는 시장에 거의 없음.
- **한 줄**: 큰 흉년이 든 산골 고을. 인색하기로 악명 높은 만석꾼 영감이 쌀을 꿔 주되 되마다 '쓸모없는 물건 하나'(깨진 바가지, 헌 짚신, 이 빠진 빗)를 받아 간다. 마을은 미친 노인이라 욕한다. 다리 밑 거지 소녀만 매번 가장 하찮은 것을 정성껏 가져온다. 봄이 오자 그 물건들이 고을을 뒤집는다.
- **주인공**: 예순 넘은 만석꾼 영감(노인 남성) + 거지 소녀(거울 인물). 미끼: 영감을 욕하는 훈장, 쌀을 더 타려 거짓말하는 이웃. 악역: 환곡을 빼돌린 아전.
- **반전 2겹**: (1) 물건은 '누가 남의 몫까지 챙기는가, 누가 거짓을 말하는가'를 가려내는 장부였다(영감은 이름 대신 물건으로 사람을 기억) → (2) 영감이 거지 소녀를 지켜본 이유: 소녀가 제 몫 한 되를 다리 밑 아이들과 나누는 것을 첫날부터 보고 있었고, 봄에 소녀 이름으로 설죽소(죽 끓이는 곳)를 연다. 아전의 환곡 비리는 '쓸모없는 물건'들의 날짜가 증거가 된다.
- **반복 단위**: 쌀 꾸러 오는 날 4회(초겨울→섣달→정월→입춘), 회차마다 물건의 뜻이 하나씩 드러남.
- **조합 제안**: 오프닝 O2(결말 먼저: 봄, 고을 사람들이 구두쇠 영감 집 앞에 엎드려 있다) / 작법 S6(인과응보 대칭: 거짓말쟁이 이웃 ↔ 거지 소녀) / 궁금증 시청자도 모름 / 배경 산골 장터·곳간 / 시대 조선 후기 대기근기(현종 경신대기근 또는 숙종 을병대기근, 원고에선 "큰 흉년이 든 해") / 인사 결말 직전 / 제목 틀 결과 선공개형.
- **제목 후보**: ① 흉년에 쌀 한 되 꿔 주며 깨진 바가지를 요구한 구두쇠 영감, 봄이 오자 고을이 발칵 뒤집힌 이유 ② 미친 영감이라 욕먹던 만석꾼의 곳간에서 봄에 나온 것 ③ 거지 소녀가 들고 온 이 빠진 빗 하나
- **문헌 걸이(H1)**: 경주 최부자 육훈("사방 백 리 안에 굶어 죽는 사람이 없게 하라"), 환곡 제도와 폐단, 조선 후기 진휼·설죽소.
- **1편과 같은 것 / 바꾸는 것**: 같음 = 장부·기록이 증거가 되는 장치(1편 바늘땀 ↔ 물건), 아전·청지기 비리. 바꿈 = 주인공 유형(노인 남성·거지 아이), 배경(산골), 시대, 작법(S1→S6), 궁금증 방식(혼합→시청자도 모름), 분위기(긴장→따뜻한 겨울 생활 묘사: 죽 끓는 소리, 아궁이, 봄나물).
- **위험**: 흉년은 무겁다 → 굶주림 묘사는 짧게, 나눔·온기 장면을 길게. 1편의 '기록이 증거' 장치와 겹치므로 물건의 뜻은 숫자가 아니라 **사람의 성품**으로 풀 것.

### 3순위. 첫 친정길에 빈 쌀자루 세 개
- **타는 공식**: C(첫 친정길 물건 수수께끼) 정면. 지금 가장 뜨겁고 가장 붐빈다.
- **한 줄**: 시집살이 삼 년 만에 첫 친정길. 시어머니는 노잣돈 대신 빈 쌀자루 세 개와 "가는 길에 세 집에 들러 채워 오너라"는 말만 준다. 세 집을 들를 때마다 시어머니의 과거가 한 겹씩 벗겨진다.
- **주인공**: 스물둘 며느리. 대비 인물: 시어머니(겉은 매섭고 속은 다른 사람). 미끼: 며느리를 동정하는 이웃 아낙(사실 시어머니를 모함한 사람), 첫 집 주인.
- **반전 2겹**: (1) 세 집은 시어머니가 옛날 쫓겨난 며느리였을 때 자기를 거둔 집들 → (2) 세 번째 집은 며느리의 친정이 아니라, 며느리가 모르는 **친어머니**의 집(며느리는 수양딸). 시어머니는 혼담 때부터 알고 있었다.
- **반복 단위**: 세 집 방문(여정형) + 집마다 쌀자루에 담기는 것이 다름(쌀→편지→사람).
- **조합 제안**: 오프닝 O4(마지막 말: "세 집에 들러 채워 오너라"의 뜻을 아무도 모름) / 작법 S2(여정: 떠남과 귀환) / 궁금증 시청자도 모름 / 배경 산길·세 마을 / 시대 조선 중기 / 인사 오프닝 직후 / 제목 틀 대사 인용형.
- **제목 후보**: ① 시집살이 삼 년 만의 첫 친정길, 빈 쌀자루 세 개만 지워 보낸 시어머니, 마지막 집 대문 앞에서 며느리가 주저앉은 이유 ② "세 집에 들러 채워 오너라" 시어머니의 말뜻을 며느리는 마지막 집에서야 알았다 ③ 첫 친정길에 노잣돈 대신 받은 빈 자루 세 개
- **문헌 걸이(H1)**: 근친(覲親) 풍속, 시집살이 노래(민요, 가사 인용 금지·새로 지음), 조선 중·후기 수양딸 관행.
- **같은 것 / 바꾸는 것**: 시장과 같음 = 공식 C 그대로. 바꿈 = 물건(개·메주→빈 자루 세 개), 구조(한 번의 반전→세 겹 여정), 결말(시어머니의 속내 + 출생 비밀). 1편과는 거의 안 겹침(S2·O4·시청자도 모름·며느리·산길).
- **위험**: 공급이 가장 많다 → 제목만으로는 묻힐 수 있음. 썸네일·첫 1분에서 '빈 자루 세 개'의 낯섦을 세게.

### 4순위. "돌로 밥을 지어 오너라" — 다리 밑 아이의 수수께끼 다섯
- **타는 공식**: E(억지 명령 + 아이의 답) + 정체 공개 + 지혜담. 중간 밀도.
- **한 줄**: 새로 온 현감이 다리 밑 거지들을 쫓아내려고 "돌로 밥을 지어 와라, 모래로 새끼를 꼬아 와라" 억지 과제를 낸다. 열 살 거지 아이가 다섯 번 다 받아친다. 그런데 과제는 현감이 낸 것이 아니었다.
- **주인공**: 열 살 거지 아이(남아). 숨은 관찰자: 현감(실은 아이의 재주를 시험해 거둘 작정). 악역: 걸인 터를 헐어 제 땅으로 삼으려는 아전. 미끼: 아이를 괴롭히는 포졸(사실 아이를 감싸는 사람).
- **반전 2겹**: (1) 과제는 아전이 현감 이름을 빌려 낸 것 → (2) 현감은 처음부터 알고 지켜봤고, 다섯 번째 과제의 답이 아전의 토지 문서 위조를 드러낸다.
- **반복 단위**: 수수께끼 5회(전래 수수께끼 설화 유형 활용, 답은 새로 짬).
- **조합 제안**: 오프닝 O6(이야기꾼의 물음: "돌로 밥을 지으라면 여러분은 무엇을 가져가시겠습니까") / 작법 S1 또는 S3 변형 / 궁금증 시청자도 모름 / 배경 관아·다리 밑 / 시대 조선 중기(명종, 토정 이지함 걸인청 시기와 겹침) / 인사 오프닝 직후 / 제목 틀 대사 인용형.
- **제목 후보**: ① "돌로 밥을 지어 오너라" 현감의 억지에 다리 밑 거지 아이가 들고 온 것, 관아가 조용해진 이유 ② 다섯 번 억지 과제를 다 받아친 거지 아이, 다섯 번째 답에 아전이 주저앉았다 ③ 거지 아이의 밥상에 돌이 올라온 날
- **문헌 걸이(H1)**: 토정 이지함의 아산 걸인청(실존), 전래 수수께끼 설화 유형, 조선 토지 문서(문기).
- **같은 것 / 바꾸는 것**: 1편과 같음 = 숨은 관찰자, 문서 위조. 바꿈 = 아이 주인공, 관아 배경, 웃음기 있는 지혜담 톤, O6.
- **위험**: 수수께끼 답이 억지스러우면 전체가 무너짐. 다섯 답을 설계 단계에서 먼저 확정.

### 5순위. 홍순언과 보은단 — 이름을 묻지 않은 역관 (브랜드 특집용)
- **타는 공식**: D(선행→뜻밖의 보은) + 결과 선공개. '문헌야담'이라는 채널 이름에 가장 정면으로 맞는 **실존 문헌 소재**.
- **한 줄**: 역관 홍순언이 북경에서 부모 장례비가 없어 몸을 팔려던 여인을 은 삼백 냥으로 구하고 이름도 묻지 않고 떠난다. 조선에 돌아와 공금 유용으로 옥에 갇히고, 이십 년 뒤 종계변무 사신으로 다시 북경에 갔을 때 성문 앞에 비단 백 필이 쌓여 있었다.
- **주인공**: 중인 역관(새 주인공 유형). 조력자: 명 예부시랑 석성의 부인(그 여인). 대비: 홍순언을 비웃던 동료 역관들.
- **반전**: 보은의 주체(여인의 현재 신분)와 보은의 크기(종계변무 해결 → 광국공신). 정체 공개가 약한 대신 '보은의 규모'로 끌고 간다.
- **반복 단위**: 북경행 3회(젊을 때 / 옥살이 뒤 / 사신으로).
- **조합 제안**: 오프닝 O2(결말 먼저: 비단 백 필) / 작법 S2(여정) / 궁금증 시청자만 앎(여인이 누가 되었는지 시청자는 먼저 안다) / 배경 한양 역관 집·북경 / 시대 선조 / 인사 첫 반전 직후 / 제목 틀 결과 선공개형.
- **제목 후보**: ① 이름도 묻지 않고 은 삼백 냥을 내준 조선 역관, 이십 년 뒤 북경 성문 앞에 비단 백 필이 쌓여 있었다 ② 공금을 써 버려 옥에 갇힌 역관이 나라를 구한 이유 ③ 보은단 — 은혜 갚은 비단 백 필
- **문헌 걸이(H1)**: 어우야담, 통문관지, 선조실록(광국공신), 서울 보은단동(을지로) 지명 유래.
- **위험**: 실존 인물·명나라 배경 → 고증 부담, 수면용 서민 장터 수요와 거리. 분량 70분 채우려면 허구 인물(동료 역관·옥졸) 비중을 늘려야 함. 조회수보다 채널 신뢰용.

# 2차 조정 (2026-10-04) — 카테고리는 고부(姑婦) 이야기, 9편은 "며느리의 신통력"

사용자 확인: 채널 카테고리를 고부간 이야기로 맞추기로 했고, 시어머니의 신통력(박씨전 계열)은 이미 2편 제작. 9편은 **며느리의 신통력**으로 자리를 뒤집는다.
1차 후보 중 3순위(첫 친정길 빈 쌀자루)만 고부 카테고리에 맞고, 나머지는 보류.

## 설계 원칙
- 박씨전 2편과의 차이: 박씨전은 **드러나는 도술**(허물 벗기, 적장 물리치기). 9편은 **조용한 신통**(꿈·눈·귀)으로 간다. 시어머니는 신통의 주체가 아니라 **의심하고 막는 사람**이었다가 믿게 되는 축.
- 고부 축이 주인공: 신통력은 사건을 만드는 장치, 이야기의 중심은 "시어머니가 며느리를 믿게 되는 과정"이다.
- 신통은 한 가지만, 한도 있게. 만병통치·전지전능으로 흐르면 긴장이 죽는다(소재저장고 v1의 경고와 같음).
- 시장 공식: 시어머니 박해 → 며느리 귀환·역전(C 변형), "며느리 눈에만 보인 것", 정체 공개.

## 후보 (추천 순)

### A. 꿈을 입 밖에 내지 말라던 시어머니 — 예지몽 며느리 (1순위)
- **한 줄**: 가난한 산골 집 며느리가 밤마다 꾸는 꿈이 들어맞는다. 시어머니는 "요망하다, 입 밖에 내지 마라"며 틀어막고 무당을 불러 굿까지 한다. 꿈이 네 번 맞고, 다섯 번째 꿈은 마을이 걸린 꿈이었다.
- **신통**: 예지몽(꿈으로만 봄, 뜻은 스스로도 모름 → 해몽이 반복 단위).
- **고부 축**: 억압 → 시어머니가 며느리를 막은 **진짜 이유**(시어머니도 젊어서 같은 꿈을 꾸다 친정과 시댁에서 요망하다고 쫓겨날 뻔했다) → 마지막 꿈을 두 사람이 함께 풀어 마을을 구함.
- **반전 2겹**: (1) 시어머니의 금지는 미움이 아니라 보호였다 → (2) 시어머니가 평생 숨긴 꿈 하나가 며느리의 다섯 번째 꿈과 같은 꿈이었다(세대를 건너 같은 꿈).
- **반복 단위**: 꿈 5회(소 잃음 → 장독 깨짐 → 시누이 혼사 → 산불 → 역병·홍수). 회차마다 꿈은 또렷해지고, 시어머니의 대응이 달라진다(윽박 → 굿 → 침묵 → 같이 풀기).
- **미끼**: 무당(며느리를 몰아내려는 듯 보이나 실은 시어머니의 과거를 아는 사람), 시누이(며느리를 모함하는 듯하나 오빠를 지키려는 것).
- **문헌 걸이(H1)**: 삼국유사 김유신 누이 보희·문희의 매몽(꿈 사고팔기) ◎ / 조선 야담의 예지몽 유형 ○ / 해몽서(주공해몽) 풍속 ○.
- **조합**: 오프닝 O4(마지막 말: "그 꿈, 누구에게도 말하지 마라") / 작법 S1 변형(시험 대신 꿈 반복) / 궁금증 시청자도 모름 / 배경 산골 농가 / 시대 조선 후기 / 인사 첫 반전 직후 / 제목 틀 대사 인용형.
- **제목 후보**: ① 밤마다 꾼 꿈을 입 밖에 내지 말라던 시어머니, 며느리가 그 말을 어긴 날 마을이 살았다 ② 며느리 꿈이 네 번 맞자 굿을 벌인 시어머니, 다섯 번째 꿈에 시어머니가 먼저 울었다 ③ "요망한 것" 소리 듣던 며느리의 꿈 하나
- **박씨전 2편과 같은 것 / 바꾸는 것**: 같음 = 신통을 가진 여인이 집안을 구함. 바꿈 = 주체(시어머니→며느리), 신통의 결(도술→꿈), 시어머니 역할(주인공→억압자였다가 동류), 결말(승리→두 여자의 연대).

### B. 지관 셋을 물리친 며느리 — 묏자리 보는 눈 (2순위)
- **한 줄**: 시아버지 상에 이름난 지관 셋이 자리를 다툰다. 며느리가 "그 자리는 물이 찹니다" 한마디를 하자 시어머니는 아녀자가 어디서 입을 놀리냐며 내친다. 지관의 자리에 모신 뒤 집안이 기울고, 쫓겨난 며느리는 제가 봐 둔 자리에 친정아버지를 모신다.
- **신통**: 풍수 신안(땅의 물길·바람이 보임). 한도: 사람 일은 못 봄.
- **고부 축**: 체면 때문에 며느리를 내친 시어머니 → 삼 년 뒤 몰락한 시어머니가 며느리 친정 대문 앞에 선다 → 며느리가 시아버지 묘를 **옮기자**가 아니라 시어머니를 **모시겠다**고 함(신통보다 사람).
- **반복 단위**: 자리 보기 4회(시아버지 묘 → 우물 자리 → 친정아버지 묘 → 시어머니가 부탁한 자리).
- **문헌 걸이(H1)**: 며느리 명당 설화(한국구비문학대계, 전국 분포) ◎ / 조선 후기 산송(묏자리 소송) 폭증 ◎ / 「택리지」 풍수관 ○.
- **조합**: O2(결말 먼저: 몰락한 시어머니가 며느리 집 대문 앞에) / S6 인과응보 대칭(지관 말 따른 시댁 ↔ 며느리 말 따른 친정) / 시청자도 모름 / 배경 중소 양반가·산 / 조선 후기 / 인사 오프닝 직후 / 결과 선공개형.

### D. 약손 며느리 — 의녀 출신 (4순위, 만병통치 함정 주의)
